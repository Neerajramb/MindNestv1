Milestones for AI-Powered Multimodal Assistive Application for People with MCI

Project: MCI Assistive Application (Django backend, mobile Patient app, Caregiver dashboard)

The project is divided into Milestone 0 and 11 Core Milestones, following the Recommended Development Order and Module Design in the Consolidated Project Specification. Milestones 1–4 can be completed in roughly any order once Milestone 0 is done; Milestones 5–11 depend on the data models and auth from Milestones 1–4. Each milestone includes a Git commit message. When completed, use a unique commit message and push your updates to GitHub.

Milestone 0: GitHub Repository Setup (Mandatory)

  • Create a private GitHub repository.
  • Add README.md with a short project description (problem, objectives, actors).
  • Add .gitignore for Python, Django, React/Vue/mobile build artifacts, and vector-store cache files.
  • Commit and push initial setup to the repository.
  • Add your guide/reviewer as a collaborator so progress can be tracked.

Milestone 2: Patient & Caregiver Data Models (MOD-02, Database Design)

  • Create models for: User, Patient profile, Caregiver profile, Patient–Caregiver relationship.
  • Create models for: Schedule/Calendar items, Medication, Reminder.
  • Create models for: Registered People (face metadata), Object observations, Conversation/memory records, Safe zones/Geofences, Activity/Audit log.
  • Define relationships (1:n, n:n where required — e.g., Caregiver–Patient, Patient–Medication, Patient–RegisteredPerson).
  • Add migrations and seed/test data.
  • Ensure authorization filters (a caregiver only sees their linked patients' data) are enforced at the model/query layer.
